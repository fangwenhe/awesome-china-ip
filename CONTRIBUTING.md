# Contributing

Thanks for helping keep **Awesome China IP** accurate and useful.

## What to add

- Verified official portals, search tools, fee schedules, guides, enforcement routes.
- Real case studies with public sources.
- Any resource that helps foreign brands/creators protect IP in China.

## Rules

1. **Verify before adding** — official sources preferred (CNIPA, CCPC, WIPO, customs).
2. **No paid placements** — this list is not for advertising agencies or agents.
3. **Format** — keep alphabetical/link-list style, one link per line with a short description.
4. **Chinese + English labels** where useful.

## How

- Open a **Pull Request** (preferred) or an **Issue**.
- For fee/rule corrections, link the official source so it can be double-checked.
